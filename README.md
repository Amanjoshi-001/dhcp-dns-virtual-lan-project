# DHCP and DNS Configuration in a Virtual LAN

## Project Overview
This project demonstrates the configuration of DHCP and DNS services in a virtual LAN environment using Windows Server and an Ubuntu client machine. The project shows how IP addresses are automatically assigned to clients and how domain names are resolved using a DNS server.

## Tools and Technologies
- Windows Server 2022
- Ubuntu Linux
- VMware Workstation
- DHCP Server
- DNS Server

## Network Architecture
Windows Server acts as the DHCP and DNS server, while Ubuntu acts as the client machine.

Server IP: 192.168.1.1  
Client IP: 192.168.1.10  

## Key Features
- DHCP server configuration
- DNS server setup
- Automatic IP address assignment
- Domain name resolution
- Network troubleshooting
